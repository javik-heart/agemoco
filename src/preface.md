# 前言

关于衰老，话太多，准的太少。

一种说法把衰老写成命运：基因决定寿命，到点就老，能做的只有认命。另一种说法把它写成商品：一只手环、一管针、一张“年轻五岁”的报告，就能把时间扳回去。两条路看起来相反，骨子里却一样——都假定衰老是**一条画死的线**。区别只在于有没有人声称自己握着橡皮。

更有用的图像不是线，而是一条还在走的路：有底盘，有速度，也有台阶。底盘是遗传和发育留给你的储备，改起来最慢。速度是这一年实际老得有多快，睡眠、体重、炎症都能把它改快或改慢。台阶则是一次感染、一次手术、一次孕期、一轮化疗——它们会把路抬高一截。有的台阶走下去还能回到原来的高度，有的会变成新的地面。

所以，这本书不承诺“变回二十岁”。那是广告。真正能做的只有三件事：让一年少跑成一年半；在失代偿之前看见冲击；同样跌倒后少掉一层储备。

谁来看见这些？手腕上的设备看见的是**已经发生的速度和台阶**。血液检查和影像确认哪个系统已经在分子或结构上动了。诱导多能干细胞——也就是把你的体细胞“倒回”接近胚胎状态、再做成心、肝、神经副本的技术——看见的是**这条路为什么会弯、会先从哪个器官弯**。三层拼在一起，才谈得上对一个人的衰老负责。单独拿出一层，说自己已经在“管理衰老”，证据都不够。

读完以后，希望你更想问三句话，而不是更想下单：

- 我现在跑多快，刚受了什么伤？
- 我天生哪里比较薄，下一次伤会先碰到哪？
- 哪一步真的值得改这条路？

第一句交给连续监测和临床。第二句交给细胞计算。第三句交给医生。问错人，衰老又会变回命运，或者变回营销。
