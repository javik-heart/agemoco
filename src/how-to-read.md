# 如何阅读这本书

这本书按一条问题链往下写，而不是按心、肝、脑分科。建议顺着读。若时间有限，可以先看这张地图，再跳到最关心的部分。

## 一张地图

| 你将读到 | 它回答 | 读完可以留下的印象 |
|---|---|---|
| 第一部 | 衰老曲线到底是什么 | 不是寿命线，是底盘、速度和台阶叠在一起 |
| 第二部 | 培养皿里的“年轻细胞”说明什么 | 那是器官风洞，不是体内年龄计 |
| 第三部 | 手环、手表能做什么 | 先建立你自己的常模，再看速度、冲击和干预有没有改趋势 |
| 第四部 | 个人细胞平台能做什么 | 找出薄点、测恢复力、预演干预、保存将来的种子 |
| 第五部 | 两者接上以后有什么用 | 七件能落实的事，以及怎样判断算不算改善 |
| 第六部 | 边界在哪里 | 哪些承诺必须拒绝 |

## 三个不要混用的层

后文会反复回到同一组分工，不妨先记在这里：

```
连续监测 + 血液时钟   → 这条路现在跑多快、刚受了什么伤
化验 / 影像           → 哪个系统已经在分子或结构上动了
个人细胞 / 类器官     → 天生哪里薄、下一次伤先碰到哪、哪种办法值得上身
医生                  → 哪一步真的改这条路
```

> [!NOTE]
> 细胞平台有一半的价值，是**拦住不该进身体的东西**。对愿意尝试各种“抗衰方案”的人，少一次伤害，往往比多一次未经验证的希望更重要。过度医疗本身，也是衰老路上的冲击。

## 怎样才算成功

请先忘掉“年轻五岁”。对个人，成功应当是能反复测到的轨迹变化：

- **几周内**：冲击之后，睡眠、心率、血糖有没有回到你自己原来的范围。
- **一季内**：腰围、血压、血糖、肝酶、炎症有没有和穿戴信号往同一个方向走。
- **一年内**：功能年龄的缺口有没有继续扩大。
- **大事之后**：手术、感染、怀孕过后，生理信号有没有在数月内回落。

翻译成健康语言，就是：**把生病前那段失能的时间压短**，让第一次心梗、第一次心衰、第一次明显的认知下降来得晚一点。不是保证能活到某个岁数。

## 这本书不是什么

它不是看病指南，不是产品说明书，更不是一张“培养皿里有效就等于人能延寿”的许可证。文中引用的大样本研究，说的是人群里的关联和机制上的可能；落到某一个人，仍然需要医生判断。附录里有术语和文献线索，方便核对，不代替原论文。
