# 如何阅读这本书

本书按论证顺序推进，而不是按器官科别推进。建议顺着读。若只想抓住可用的结构，可以按下面的地图跳。

## 一张地图

| 部分 | 回答的问题 | 读完应留下的句子 |
|---|---|---|
| 第一部 | 衰老曲线到底是什么 | 不是寿命线，是 set-point、pace 与 shocks 的叠加 |
| 第二部 | iPSC 测的是什么、不是什么 | 器官风洞，不是体内年龄计 |
| 第三部 | 穿戴能做什么、只该做什么 | 建立本人常模，看斜率、冲击和干预是否改了速度 |
| 第四部 | 细胞平台的四项任务 | 薄点、恢复力、预演、种子 |
| 第五部 | 两者耦合后对个人有何用 | 七类可落实作用，加上可重复测量的成功标准 |
| 第六部 | 边界在哪里 | 一条可辩护的命题，以及它的禁区 |

## 三个不混用的层

后文会反复回到同一组分工。不妨先记在这里：

```
穿戴 + 血液时钟     → 这条曲线现在跑多快、刚受了什么伤
临床化验 / 影像     → 哪个系统在分子或结构上已经动了
iPSC / 类器官      → 天生哪里薄、下一次伤先裂哪块、哪种干预值得上身
执业医师           → 哪一步真的改这条曲线
```

> [!NOTE]
> 细胞平台的健康作用，有一半是**减少有害干预**。对资源充裕、愿意尝试各种“抗衰方案”的人，这一点的分量不亚于发现有效干预。过度医疗本身就是衰老曲线的冲击源。

## 成功标准先说在前头

不要用“年轻五岁”当 KPI。对个人，成功应当是可重复测量的轨迹改变：

- **周**：冲击后是否回到本人包络。
- **季**：代谢与炎症是否同向改善。
- **年**：功能年龄缺口是否不再扩大。
- **事件年**：手术、感染、孕后，生理年龄是否在数月内回落。

曲线改善的临床翻译是：**压缩发病前的失能时间**，降低第一次心梗、第一次失代偿心衰、第一次显著认知下降的提前量。不是保证寿命上界。

## 这本书不是什么

它不是诊疗手册，不是产品说明书，也不是把皿里有效直接写成人体延寿的许可。文中引用的规模研究说明的是**群体相关与机制可能性**；落到某一个人，仍需临床判断。附录提供术语和证据线索，便于核对，不代替原文。

从下一章开始，先做一件看起来最不像“抗衰”的事：把曲线说准确。
