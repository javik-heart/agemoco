# 如何阅读这本书

## 两个读法

正序：前言 → 总图 → 测量学 → 第一到六部。总图把三条过程和失败分支放在一页上；测量学是后面所有“缺口扩大了”“落在尾部”的前提，不建议跳。

倒序：如果只想检验这本书是不是能运转，先读第五部的「一个人的十二周」，再用病例里的问句回头核对相应章节。不同意剂量或是否该上某种药，可以；但请在同一套尺子上争：常模、误差带、队列 N、回落，而不是争形容词。

## 地图与跳读

| 部分 | 它回答 | 建议用时 | 可以跳读的条件 |
|---|---|---|---|
| 前言 + 总图 + 测量学 | 尺子会错、闭环会长什么样 | 40 分钟 | 不跳。测量学是后面所有数字的前提 |
| 第一部 | 底盘、速度、台阶分别是什么 | 1.5 小时 | 已熟悉 set-point / pace / shock 三分法可快翻 |
| 第二部 | 培养皿里的“年轻”说明什么 | 1.5 小时 | 要审一家细胞公司：本部 + 第二十一章必读 |
| 第三部 | 手环能做什么、误差在哪 | 2 小时 | 只关心穿戴：本部 + 测量学 + 第十一章 |
| 第四部 | 薄点、恢复力、预演、种子 | 2.5 小时 | 同上，细胞公司必读 |
| 第五部 + 一个人的十二周 | 闭环能不能在一个人身上运转 | 2 小时 | 想检验本书是否可操作：直接读病例再回头 |
| 第六部（第二十一章必读） | 哪些承诺必须拒绝 | 1 小时 | 不跳第二十一章 |

审任何一家“个人抗衰细胞平台”，请先问四句（第十三章展开成清单，关于本书再挂一次）：

1. 有没有画出这个人的薄点，还是只出示重置后的年轻照片？
2. 有没有把老年环境加回去，还是在干净培养基里表演？
3. 有没有在副本上预演益损，并把有害档拦住？
4. 有没有把种子和今天的治疗分开？

四问缺一，就还不是在管理曲线。细胞平台常常更重要的功能是拦住不该进身体的东西，细节见第十六章。

## 三个不要混用的层

```
连续监测 + 血液时钟   → 现在跑多快、刚受了什么伤
化验 / 影像           → 哪个系统已经在分子或结构上动了
个人细胞 / 类器官     → 哪里薄、下一次伤先碰到哪、哪种办法值得上身
医生                  → 哪一步真的改这条路
```

职责对照表只在这里和第十八章出现一次，第五章不再重复铺一张大表。

## 怎样才算成功（先看方向）

请忘掉“年轻五岁”。对个人，成功是能反复测到的轨迹变化：几周内冲击能否回到自己的范围；一季内代谢和炎症是否与穿戴同向；一年内功能缺口是否不再扩大。翻译成健康语言，是把发病前那段失能压短，不是保证活到某个岁数。完整规则在第二十章。

## 这本书不是什么

它不是看病指南，不是产品说明书，更不是“培养皿有效等于人能延寿”的许可证。大样本研究说的是人群里的关联和机制上的可能；落到某一个人，仍然需要医生判断。附录是证据网，方便核对，不代替原论文。
