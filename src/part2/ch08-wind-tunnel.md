# 第八章 个人器官风洞

<span class="part-kicker">跑多快 · 哪里薄 · 哪一步值得改</span>

飞机的风洞不证明这架飞机已经飞过大西洋。它只证明：在可控气流和故障模式下，机翼会不会先抖，改一个零件会不会把抖的位置挪走。个人细胞和类器官平台的正当位置，就是这种风洞。它回答条件句，不签发航线证书。把风洞照片贴上“已安全飞越大洋”，是第六章那种混用尺子；把风洞照片贴上“已延寿”，是把几天培养写成几十年寿命。

新方法学名称是 NAM（new approach methodologies，新方法学），指减少动物实验依赖、提高人体相关性的模型，包括细胞、类器官、器官芯片和某些计算替代。名字是监管和研发里的分类标签，不自动赋予临床效力。一个心肌芯片可以是合格的 NAM，仍然当不了这人心衰的诊断器，也当不了某瓶保健品的延寿证明。遇到把“我们采用 NAM”写成“已经临床验证”的句子，先停：名称和效力不在同一层。

NAM 的正当来历，是减少不必要的动物实验、在人体相关系统里更早看见毒性或无效。正当来历帮不了个人抗衰报告。监管分类里合格，只说明你没有用一种已经被淘汰的借口去代替动物；临床效力要另有适应症、剂量、安全性和终点。风洞可以是很好的 NAM，仍然必须把自己写成条件句。把方法学进步写成已经飞过大西洋，是比喻自己拆掉自己。

比喻也有边界。飞机风洞控制的是气流速度、攻角和已知故障模式。人体芯片控制的是培养基、血清批次、剪切力和加药时间。气流相对干净；血清是脏的，人与人不同，同一人的不同采样日也不同。所以风洞比喻只借“可控压力下看哪里先抖”，不借“通过适航认证”。适航在医学里是指南、随机证据和医生的适应症判断。芯片没有适航章。第六章若被读懂，读者不会向风洞要体内年龄；本章若被读懂，读者不会向 NAM 要临床效力。

第六章把两把尺子拆开，第七章把留下的三层摊开。本章把它们收成一份细胞报告模板：合法输出只有三句，校准不够则三句都不能用。禁令的细则在第二十一章。本章只保留禁止事项的标题，让读者看见风洞不该被写成什么，然后把篇幅留给它该写成什么。

## 合法输出是三句条件句

像样的风洞报告开头不该是生物学年龄。它应当给出下面三句，并且每句带着自己的前提。缺前提的句子，降为实验室演示，不得进入个人决策。

1. **相对脆弱**：在写明的标准压力、分化日龄和成熟标志下，这个人的模块是否相对参考分布偏尾。没有足够大的队列，只能写本室历史范围，不能写人群百分位。句子形状像：肝样模块在脂负荷四十八小时后，脂滴面积高于本室同协议历史范围（n=二十八）的上沿；心肌模块对治疗窗内某药的动作电位时程变化不在本室历史范围的上尾。
2. **恢复力类型**：老年环境或药物冲击后，功能是弹回，还是变成新地面。句子形状像：撤掉老年血清七十二小时后，胰岛素相关读数回到冲击前；或：同等脂毒撤除后，脂滴和炎症分泌仍停在高位，提示储备薄。弹回和新地面都是类型，不是分数。
3. **益损预演**：候选办法是有好处、没信号，还是有毒性。无适应症组合走有害档就拦住；有指南的药，芯片最多改监测强度和选择顺序，不改“要不要治疗已有适应症”。句子形状像：该组合在肝模块出现毒性读数，建议不上身；或：该降脂药在心肌模块未显示异常的动作电位时程（APD, action potential duration）延长，仍按指南使用，加密心电图监测。阳性对照用已知的 hERG（human Ether-à-go-go-Related Gene，编码 IKr 钾通道）阻滞剂，对照不动则整句作废。

三句合在一起，才构成一份细胞报告模板。只有脆弱、没有恢复力，你会把一次急性吵闹写成命运。只有预演、没有脆弱图，你会在错误的器官上试药。只有漂亮的年轻照片、没有这三句，那是非法输出，不是风洞。

培养皿有效仍需人体证据；培养皿有害，已经足够让高风险组合不要进身体。这两种不对称必须写进同一段。假阳性毒性会剥夺有效治疗，假阴性会放进有害组合，第十六章把两种错误写进检测效能。本章先把报告的语法定住：条件句，不是喜报。

APD 在心肌模块里是复极是否被拖长的常用读数。没有对照的 APD，不能支撑上面第一句里的“相对脆弱”。hERG 阻滞剂若不能按预期延长它，当天这台风洞等于没有风。

把三句填成模板，字段应能被另一位实验员复核。建议至少包括：模块与协议名称；分化日龄与成熟标志是否过关；压力种类、浓度、时长；阳性对照化合物及是否按预期方向变动；阴性对照是否安静；重复次数与批次方差；参考分布的 N 和来源（本室历史 / 外部队列）；血清自体或异体及采样日；相对位置用的语言（历史范围 / 百分位，后者需区间）；恢复力观察窗及是否弹回；预演对象、暴露是否接近人体、益损三档；未做的模块与未做的并列尺子。字段缺了可以降级，不能靠文案补。

假想填法如下。相对脆弱：肝样模块，分化第十八天，成熟标志部分过关；脂负荷四十八小时；本室同协议历史范围 n=二十八；脂滴面积偏高；阳性肝毒对照跑通。恢复力：撤除脂负荷七十二小时，脂滴回落不完全，炎症分泌仍高，记为新地面倾向。益损预演：无适应症组合 X 在肝模块出现毒性读数，心肌模块 hERG 对照跑通且该组合未显示额外 APD 延长；结论为组合 X 不上身，已有他汀适应症不因此改变，建议加密肝酶监测。这样的段落不漂亮，可追溯。把同一数据改写成“生物年龄年轻十一岁，建议年轻因子”，字段还在，句子已经非法。

恢复力类型值得单独说清楚，因为它最容易被做成性格学。弹回意味着：冲击造成的功能偏离，在撤除压力后回到冲击前包络。新地面意味着：偏离在观察窗结束时仍在，成为后续实验的新基线。中间态也存在：部分读数回来、关键读数不回来。中间态必须拆开写，不能平均成一个恢复力分数。分数会把肝脂没回来、心肌电回来了焊成“百分之六十二恢复”，医生无法动作。类型是为了动作：新地面倾向的人，监测加密、避免再叠加能躲开的打击；弹回的人，不必把一次芯片吵闹写成终身薄点。类型仍旧是条件句，受日龄、血清和 N 约束。

## 校准要求：否则“尾部”不可操作

最低清单不是礼貌，是这三句话能不能成立的条件。缺任一项，报告降为实验室演示。

- **分化日龄**：写到天。同一协议第十四天和第二十八天的心肌，电活动和代谢可以不在同一个世界。日龄未写，等于尺子没有刻度。
- **成熟标志物，以及未成熟表型是否仍主导**：心肌看成人同工型、特定离子通道和结构蛋白是否出现；神经元看突触与电活动是否还停在早期。标志物不过关，脆弱句必须降档为“未成熟背景中的观察”。
- **阳性对照**：心肌模块用已知 hERG 阻滞剂，应当能延长 APD；肝模块用已知肝毒化合物，应当能改变事先约定的读数（转氨酶样泄漏、胆汁转运、活率等，以协议为准）。对照不动，整批作废，不是“这次碰巧很安全”。
- **阴性对照**：溶剂和无关化合物不该乱响。阴性对照乱响，说明系统太闹，任何毒性句都不可用。
- **批次重复**：至少独立分化或独立芯片重复，报告批次间方差。同一供者换一瓶血清、换一个技术员，脂滴面积或 APD 分布都可以平移。单次漂亮结果，优先当成批次故事。
- **参考队列 N**：健康供者同协议分布。没有公开的最小 N 适合所有模块，但方向性底线可以写死：对照细胞系加阳性药要先跑通；同协议下健康供者参考至少要能画出分布，而不是三五个点。N 不够，禁止百分位语言，只允许写相对本实验室历史范围偏高或偏低。声称人群第 95 百分位时，还必须报告该百分位的置信区间和批次间方差——多数个人实验室到不了这一步，就不要用这一步的词。
- **血清来源**：自体或异体必须标明。异体老年血清测一般老年血液，外推到个人降一档；自体更接近这个人的循环，但取样时点（感染、用药、进食）仍是条件。第十五章展开，报告上不得省略这一行。

队列语言是最容易被销售改写的一行。本室历史范围回答的是：相对于我们以前用同一协议做过的人，这次偏高还是偏低。人群尾部回答的是：相对于某个抽样框里的人群分布，这个人落在哪里。前者是实验室记忆，后者是流行病学主张。记忆可以很小；主张必须有 N、有抽样说明、有区间。N 不够却写“您位于人群危险尾部”，是把风洞升级成了它没有的统计权力。

为什么 N 不够就不能谈人群尾巴，需要一句测量学而不是一句谦虚。百分位是分布里的位置。三点画不出稳定的第九十五百分位，三十个点在批次方差很大时也画不稳。置信区间会宽到把“偏尾”和“中间”叠在一起。实验室历史范围不假装自己是人群：它只说，在我们见过的同协议样本里，这次靠上沿或靠下沿。靠上沿可以启动重复实验和临床加密，不能启动“您属于最危险的百分之五”。若将来有多中心、同协议、抽样框清楚的参考队列，百分位语言可以升级，并且必须带着区间一起升级。在那之前，降级是能力，不是谦辞。

阳性对照失败时，整批作废的理由同样具体。已知 hERG 阻滞剂若不能延长 APD，可能是通道表达不够、成熟度不够、电极或光学读数坏了，或化合物没加进去。这时任何“该人心肌安全”都没有根据。已知肝毒化合物若不能改约定读数，肝模块的脂滴故事同样停摆。阴性对照乱响，则任何“该组合有毒”都可能是系统过敏。对照不是礼仪性的加药，是这台风洞当天有没有风的证明。批次重复则防止把一个技术员的手劲写成这个人的命运。同一供者独立分化两次，若脂滴从中间跳到上沿，个人结论必须让位于方差；应写“批次不稳定，不进入决策”，而不是挑好看的那一次。

血清来源和分化日龄会联合制造最像疗效的假象。用年轻商品血清把已经重置的模块养得更漂亮，再把它和老年异体血清下的同一模块对比，箭头当然会动。动的是环境，不是这个人被逆龄。合法报告把箭头写在恢复力或微环境层，并标明血清来源。非法报告把箭头写在生物学年龄栏。第八章守住字段，第七章守住三层，第六章守住两把尺子，三章其实在挡同一件事：不要让培养条件的成功，冒充人体的成功。

血清、日龄和成熟度还会联合造假象。分化偏早的肝样细胞脂肪本就堆得难看，老年血清再推一把，脆弱句会偏黑；分化较充分、却用了年轻商品化血清，脆弱句会偏白。所以校准项不能单项打勾。合法报告把它们写成同一段落的前提，而不是分散在附录里当装饰。

单模块和多模块的权限不同。只做心肌，第一句合法输出最多谈到相对复极脆弱，不能谈到全身储备。脂肪–肝轴芯片多做了一截器官间传递，仍不能签发神经结论。报告标题若写成“个人衰老全景”，权限已经被偷。模板里的未做模块清单，就是权限表。预演同理：在肝上看见毒性，足以拦住无适应症组合；在肝上没看见毒性，拦不住心肌上的通道风险，除非心肌模块也做了、对照也跑通。风洞的诚实来自它承认自己窄。NAM 作为名称，鼓励的是人体相关和少用动物，不是鼓励一张芯片覆盖衰老的全部支柱。覆盖不足的细则在第二十一章；本章只要求标题不要假装覆盖。

益损预演还要防止浓度戏剧。把保健品堆到培养基里从未在人体血液中出现的浓度，线粒体读数当然可以动，肝也可以被烫到。戏剧产生的有害档，会剥夺可能无害的选项；戏剧产生的有益档，会送人去买达不到该浓度的瓶子。模板字段里的“暴露是否接近人体”，是第三句的命门。接近不了，就写“浓度外推不足，不进入决策”。第十六章会把三档写全；本章把字段留下，否则风洞会变成特效车间。肝毒阳性对照的选择同样不能随便：协议里事先约定的化合物和读数，才有资格宣布“这批肝模块当天有反应能力”。临时换一种会让细胞变圆的试剂，不是阳性对照，是事故。

## 三句模板怎样填，怎样拒绝填

相对脆弱这一句，拒绝填的情况包括：成熟标志未过、阳性对照未动、只有一次分化、N 小到画不出范围却想写百分位。这时可以写演示记录，不能写给医生当决策输入。恢复力这一句，拒绝填的情况包括：没有撤除压力的阶段、观察窗短到只看见急性应激、没有把冲击窗口和基线分开。益损预演这一句，拒绝填的情况包括：候选物浓度与人体暴露对不上、没有同时看目标器官和毒性器官、把“没测到坏处”写成“证明有好处”。

填的时候用同一种语法。先写模块和压力，再写对照是否跑通，再写相对于什么范围，最后才是那句条件结论。结论后面必须有“不改变已有适应症”或“建议加密监测”这类把权力交回临床的尾巴。没有尾巴的风洞，会在门诊里越权。

拒绝填，比硬填更像医学。实验室已经花钱分化了两批细胞，销售会要求必须有百分位。测量学的回答是：没有分布就没有百分位，演示记录可以归档，决策输入必须空着。空着会让人难受，难受是功能：它阻止把 n=八写成人群尾巴。同样，成熟标志部分过关时，相对脆弱句可以降档写，不可以升档写。降档的句子仍然有用——它告诉医生这批细胞今天只能当线索，不能当判决。风洞的产品压力永远是把线索做成判决。校准清单存在，就是为了让判决在条件不足时自动失败。失败应当被看见，并且被写进第十八章那种允许失败的闭环，而不是用年轻照片把失败盖住。

非法输出三条，标题如下，细节并入第二十一章：

- 用年轻外表证明逆龄
- 用一次芯片宣布延寿
- 用单模块签发临床诊断

本章只保留标题。读者若在任何细胞公司的页脚看见这三句的完整版，应当把报告读成广告。风洞标明的是：更可能从哪条系统开始失代偿，冲击后更像弹回还是更像新地面，某个候选办法在副本上偏益还是偏损。它不代替心衰或痴呆诊断书，不代替终点试验，也不代替医生选择哪一步值得改。

把三句条件句读给非实验室的人听，可以用同一架飞机把比喻说完。相对脆弱：在这种风速和这个攻角下，这块机翼比我们库里见过的多数机翼更先抖。恢复力：把风速降回去以后，抖是停了，还是留下一道新的缝。益损预演：换一枚螺丝，抖是减轻、不变，还是把裂缝换到了别处。三句都没有说这架飞机今年已经飞了多少小时，也没有说乘客已经更年轻。NAM 可以是建造这台风洞的理由，不是签发航线的理由。N 不够时，连“比多数机翼更先抖”都要改成“比我们库里那几架更先抖”。改词不是示弱，是让句子还能被下一次重复实验打死。打不死的句子，才有资格进入第十八章那种闭环；打死了，就停。停，是风洞对健康的负向贡献，和第十六章拦住有害组合是同一类事。

第三部进入穿戴。没有真实世界的速度，风洞再精致，也不知道路上是不是真的在弯。反过来也成立：没有风洞的条件句，手表上的弯也解释不了是肝、是心，还是呼吸在碎。两件事要接，但接的起点是各自先把自己的合法输出写干净。
