# 第十六章 干预的预演场

衰老干预最大的浪费，是把群体有效的手段用在机制不匹配的人身上。更大的伤害，是把群体无效甚至有害的手段，用在愿意付费的人身上。平台可以把候选干预分成三档，只允许上身“细胞端有正向信号或至少无害”的。

## 上身之前先问的问题

| 干预类型 | 在个人模型上先问什么 | 与曲线的关系 |
|---|---|---|
| 睡眠 / 运动 / 减重 | 穿戴已显示斜率，细胞端看肝脂、内皮炎症是否同向改善的机制空间 | 改实现斜率 |
| 降糖、降脂、降压、GLP-1 等正规药 | 心肌电生理、肝毒、肌管 / 胰岛功能 | 减少代谢冲击 |
| 保健品、跨境“抗衰”组合 | 有无线粒体、蛋白稳态、SASP 改善，有无肝心肌毒性 | 防止把冲击当干预 |
| 未来的部分重编程、senolytic | 只在研究协议下，看功能恢复 vs 基因组不稳定 | 高风险，必须风洞先行 |

三档的意思是：

- **正向或同向**：细胞端出现可解释的改善，与穿戴或实验室方向一致，值得在医生监督下上身或继续。
- **无信号**：既无益也无明显害。对生活方式手段，可以继续用真实世界趋势做决定；对注射、跨境药和堆叠组合，无信号等于不应上身。
- **有害**：肝、心肌、节律、基因组不稳定出现信号。这一档的正确动作是阻止，不是加到下一个疗程里“观察一下”。

## 减少有害干预，本身就是健康贡献

细胞平台在这里的健康作用是**减少有害干预**，重要性不亚于发现有效干预。对高收入人群尤其如此：过度医疗本身就是衰老曲线的冲击源。一次药源性肝损、一次不必要的心律失常、一轮来路不明的“年轻因子”，都会把冲击写成新平台。风洞若能在上身前把它们拦下，它对曲线的贡献已经大于又一次未经验证的逆龄叙事。

正规药也要预演，但伦理不同。降糖降脂降压有终点试验，上身的理由不来自芯片。芯片在这里问的是**这个人的心肝是否落在危险尾部**，从而调整选择和监测，而不是决定“要不要治疗代谢病”。把风洞置于指南之上，是另一种过度。

> [!CAUTION]
> 部分重编程和 senolytic 写在表的最后一档，不是为了点缀前沿。它们改的是细胞身份和存活，风险与收益都不属于消费级抗衰。没有研究协议，就没有上身。风洞先行是最低条件，不是充分条件。
