# 第二十章 怎样才算改善

<span class="part-kicker">跑多快 · 哪里薄 · 哪一步值得改</span>

请不要用“年轻五岁”当成绩单。对个人，成功应当是能反复测到的轨迹变化。变化有时间尺度。尺度错了，就会把噪声当成逆龄，或把还没走完的回落当成失败。第十九章列出七件能落实的事；没有这一章的尺子，七件仍可被讲成故事。故事的特征是：任意一只钟动了就算赢，化验变坏可以假装没看见，一年尺度的储备从未测量却被写成“功能年轻了”。

| 时间 | 看什么 | 谁来测 |
|---|---|---|
| 几周 | 冲击后有没有回到自己的范围（心率变异、睡眠、静息心率、连续血糖） | 穿戴 |
| 一季 | 代谢和炎症有没有同向（腰围、血压、糖化血红蛋白、肝酶、超敏 C 反应蛋白） | 实验室 |
| 一年 | 功能年龄缺口有没有继续扩大；器官储备测试恶化有没有变慢 | 穿戴钟 + 影像 / 功能试验 |
| 大事之年 | 手术、感染、怀孕过后，生理信号有没有在数月内回落 | 穿戴的纵向记录 |
| 研究层 | 个人类器官在老年血清里的失能有没有减轻 | 细胞平台 |

表可以一眼看完。读表的方法不能一眼看完。下面把每一行的成功、失败、冲突和空窗写清楚。空窗的意思是：你没测那一行要求的东西，这一行就保持空白，而不是用另一行的数字去填。

## 几周：成功是闭合，不是分数变好看

几周的成功是闭合：冲击发生了，范围收回来了。收不回来，就还在冲击里，不应开始庆祝任何分数。感染、时差、一次过重的训练、化疗周期中的塌陷，都适用同一句。闭合看的是本人包络，不是人群参考区间。HRV 回到自己病前的夜间中位附近，比“应用显示恢复力 82 分”更有意义。设备睡眠分期回到冲击前的结构，不等于多导睡眠图（PSG, polysomnography）意义上的慢波回来了；这一行允许用设备睡眠当过程指标，不允许把过程指标挂上痴呆文献。

连续血糖监测（CGM, continuous glucose monitoring）可以进入几周这一行，但必须降档：它在糖尿病管理里证据厚，在非糖尿病人群里薄。餐后峰变窄、变异系数下降，只能写成代谢波动的辅助，不能写成已经诊断或已经治愈了糖代谢病。几周行里没有 CGM，并不自动失败；用了 CGM 却把它当成硬终点，反而是误用。

几周行最常见的自欺，是把滚动常模打开，让未回落的数据自己把自己吃成“新的正常”。测量学把冲击窗口列为不得进入基线更新的硬约束。成功标准必须站在同一条约束上：窗口结束仍未闭合，记为未回落，交给医生，而不是交给平均算法。

## 一季：成功是同向，冲突时先信实验室

一季的成功是同向：腰围、血压、糖化血红蛋白（HbA1c）、肝酶、超敏 C 反应蛋白（hs-CRP）不必每一项都完美，但方向应和手环上的速度一致。同向不是“全部变绿”。一个人腰围降了、血压还在原地、肝酶略降、HRV 回到包络下沿，已经够写成同向。一个人只把步数刷高、腰围和炎症不动，只够写成穿戴层部分响应，不够写成代谢改善。hs-CRP 还要防急性噪声：一次牙周发作或一次感冒可以把炎症推高，不代表代谢杠杆失败；反过来，慢性低水平升高被“本周分数不错”盖住，也不代表炎症账户已结。一季行看的是跨月方向，不是某一张化验单的戏剧性。

冲突规则必须升级成可执行的两句，不能停在“要综合看”。

**正向冲突：穿戴变好，肝酶变坏，先信实验室。** 夜间 HRV 回升、静息心率下降、应用里的缺口也在收，但 ALT、AST 或 γ-谷氨酰转移酶走高，优先相信实验室。回头查三件事：传感器有没有换、佩戴有没有松、人有没有真的按处方做——以及有没有新的酒、药、减重过快或未申报的保健品。手表可以在炎症和肝细胞损伤之前先动，也可以在肝已经受伤时仍被睡眠债的短暂偿还所欺骗。实验室不是永远正确，但它在这一类冲突里是更靠近器官损伤的尺子。先信实验室，意思是先停庆祝、先查损伤，不是把穿戴扔进垃圾桶。

**反向冲突：实验室平坦，冲击却没有回来，不得宣布成功。** 肝酶、HbA1c、hs-CRP 可以纹丝不动地停在参考区间里，因为参考区间是为疾病诊断切的，不是为储备切的。若手术后三个月步数和 HRV 仍停在新平台，或感染后六周夜间心率仍高一截，化验单上的“正常”不能盖章。这一句是专门用来防止年检思维从后门回来的：点没有越线，不等于台阶已经走完。林某的十二周会用到反向规则的弱形式——酶没变坏，不等于可以宣布逆龄；若酶没变坏而黄体期 HRV 仍在包络外，连“几周闭合”都不能写。

两句合在一起，才是冲突规则。只记前半句，系统会变成“化验暴政”，把所有功能信号当成情绪。只记后半句，系统会变成“手表暴政”，把一次未校准的缺口当成病情。第十八章要求医生负责问哪一步值得改；冲突发生时，值得改的常常是问题本身，而不是再加一针。

## 一年：没有定义的储备测试，这一行保持空

一年的成功是缺口不再扩大，储备测试的恶化变慢。这是在压缩发病前那段失能时间，不是在抬高寿命天花板。缺口可以用 PpgAge 一类穿戴钟来追踪，但穿戴钟有误差带，也有队列偏倚，测量学专章会拆开。一年行若只用缺口、不用储备测试，写出来的成功会瘦成一句广告。

器官储备测试必须事先定义。本书把下面三项当作年尺度 KPI 的最小集合；用了等价试验，要在记录里写明等价关系，不能口头替换。

**最大摄氧量（VO2max）或等价有氧试验。** 心肺运动试验给出的 VO2max 是经典储备量。做不起或不适合的人，可以用六分钟步行、台阶试验或经过校准的亚极量方案，但必须固定协议：同一坡度或同一走廊、同一鼓励词、同一停表规则。误差来自努力程度、近期感染、贫血、β 受体阻滞剂、设备校准和测试人员的口气。一次感冒后的“VO2max 下降”不是衰老加速。一次被教练喊出来的“进步”可能只是熟悉了跑台。没有基线，就没有年变化。

**握力。** 握力与全因死亡、失能的队列关联反复出现，测量便宜，也因此最容易被随手测坏。必须固定利手、体位、Dynamometer 型号和三次取值规则。关节炎、近期手腕伤、测量者换人，都会制造假变化。握力不是“肝账户”，它是全身肌骨和神经驱动的粗指标。变好了，不能写成肝芯片成功；变差了，要先问是不是手疼。

**一套认知成套测验。** 成套，而不是手机上一分钟反应时。记忆、注意、执行功能至少要有可重复的版本。练习效应是主要误差：第二次、第三次做同一套题，分数会自己往上走，尤其在记忆分测验上。没有平行版本或可靠变化指数（RCI, reliable change index）一类门槛，一年后的“认知年轻了”可能只是熟能生巧。抑郁、睡眠债、抗胆碱药物和未纠正的听力下降，都会压低成绩，它们首先是临床问题，不是衰老钟问题。

三项都可以被更适合这个人的试验替换：有膝关节病变就不要死磕跑台；有严重手病就不要把握力当成唯一肌骨指标；已经有神经科随访就用临床正在用的成套，而不是再买一套抗衰 App。不可替换的是原则：**年尺度 KPI 必须在干预开始前定义；没定义，这一行保持空白。** 空白不是失败，空白是你还没有测量你声称在管理的东西。用 PpgAge 的零点几岁去填空，等于把过程指标晋升为储备终点。

影像可以进入一年行，但要克制。颈动脉内膜、肝脏超声或瞬时弹性、体成分，都可能提供结构侧的同向证据。没有前后可比的协议，影像和手表一样会制造噪声。一年做一次、协议固定，才谈得上恶化有没有变慢。

## 大事之年与研究层：回落属于事件，年轻不属于客户

大事之年的成功是回落。孕期生理年龄上升可以是预期中的循环重配置；产后数月仍不回来，才是问题。手术和感染同理。把孕期缺口打印成生物学年龄并配商品，既冒犯测量学，也冒犯产科常识。这一行的时间窗跟第四章走：普通感染数周，手术约三个月，分娩约六个月，化疗按方案跨数月。窗还没到就宣布失败，和窗过了还假装在恢复，是对称的两种错。大事之年可以和几周行叠在同一个人身上，但两行不要互相冒充。化疗周期中第 14 天 HRV 开始回一点，只够写几周行的“开始闭合”；能不能算这一年的储备少削一层，要等方案走完、按第十九章的时间线看下一针有没有减档。孕期缺口在分娩当天很好看，也不许提前结算产后六个月的回落。事件行的日历是事件自己的，不是应用的自然周。

研究层的成功属于风洞自己：老年血清里的失能有没有减轻。它可以支持下一轮预演，不可以直接写进客户的年龄。芯片上四天表型减轻，说明这个人的组织模型对某种内环境变化有反应，仍然不是寿命被改写。把研究层成功抄到几周行或一年行，是两把尺子混用，第六章已经用对照页禁止过。本章只补一句操作：研究层可以没有数字，几周行和一季行不能用研究层的数字来充数。防火墙还有一扇：即便复测肝模块脂滴从本室上尾回到中位，十二周的成功仍然要由手环和化验来写。模块改善是预演变准的证据，不是客户变年轻的证据。林某十二周未复测肝模块，正因为这一行不是十二周 KPI。

## PpgAge 动了零点几岁，不是逆龄

缺口有用，是因为它把“我感觉还行”翻成可以顺着时间追踪的差。缺口有害，是当它被打印成已经年轻或已经老去的岁数。消费级光电容积脉搏波会随肤色、运动伪迹、灌注和换表一起跳。一次 0.6 岁的缺口移动，常常落在该设备在这个人佩戴条件下的估计误差带里面。误差带里面的移动，方向可以记，幅度不能写成逆转，更不能写成“年轻了零点六岁”。林某十二周里会看到 +4.0 到 +3.4 的移动；那一章会把它写成缺口未继续扩大，不写成逆龄。规则在这里先钉死，免得病例章看起来像临时开恩。

若误差带从未被该设备、该肤色、该佩戴侧估计过，0.6 岁就更不能用。没有误差模型的缺口，连过程指标都不够格，见测量学专章。

## 年尺度内部也会打架，不许用周尺度去和

三项储备测试同向变好，一年行才比较好写。它们打架时，要按机制读，不要按平均分读。减重成功的一年，VO2max 可能因体重下降而表面上改善，握力却因蛋白质摄入不足或缺乏抗阻而下降：有氧行在动，肌骨行在变差，不能写成“储备全面年轻”。反过来，握力上升而认知成套停滞，可能只是手的熟练或测量者换了口气，不能写成“大脑储备跟上了”。一年行允许写“有氧改善、肌骨未改善、认知因练习效应无法判定”——这比一个合成的“功能年龄下降两岁”更接近管理。

练习效应要当成误差模型的一部分，而不是当成好消息。认知成套若没有平行版本，第二次成绩的上升优先记为熟悉题目。VO2max 也有学习效应：第一次上跑台的人，第二次常会少抓扶手、少害怕口罩。协议里应写：基线最好测两次取稳定值，年检比较用同一套鼓励词。握力三次取值取最佳或取均值，规则必须前后相同。规则变了，数字没有资格进一年行。

更不允许的是用几周行去填一年行。HRV 在十二周回到包络，只说明冲击闭合或短期杠杆有效；它几乎不告诉你最大摄氧量的年斜率。PpgAge 缺口未继续扩大，只是过程指标，填不了 VO2max、握力、认知那三格。林某十二周没有这三项基线，一年行就必须空着——空着是诚实，用 +3.4 的缺口去填是把过程指标晋升为储备终点。

误差带本身也要有算法，不能口头说“大概有误差”。最低做法：换表重叠周、同一作息下的缺口日波动、该肤色队列若有公开的均方根误差，取其中较宽的一档作为个人临时误差带。0.6 岁若落在这档里面，方向可记，逆龄不可写。没有这档，0.6 岁连方向都要降级为“疑似噪声”。第二十章把 0.6 岁写成禁令，测量学负责解释它为什么常常只是噪声。

## 翻译成健康语言

曲线改善，翻译过来就是：**把发病前那段失能的时间压短**，让第一次心梗、第一次心衰、第一次明显的认知下降来得晚一点。不是保证能活到某个岁数，不是抬高寿命天花板。压缩失能和抬高天花板是两件不同的事。前者关心的是能走、能抓、能记住、能从一次感染里回来；后者关心的是死亡日期的右移。本书的合同只覆盖前者。后者需要另一类终点试验，风洞和手环都签发不了。

流行病学里有一个相近的词：发病前失能的压缩（有时被称作 morbidity compression）。本书借用它的方向，不假装已经在个人身上测到了人群的健康寿命。个人能反复测到的，是走得动、抓得住、记得住、冲击后回得来。测不到的，是死亡日期向右移了几年。两件事被广告写成一件，成功标准就会膨胀成寿命合同。

也可以用反例把翻译钉死。两个人都被通知“年轻了五岁”。甲：手术后三个月 HRV 未回，ALT 升高，握力年降超过仪器误差，只是应用里的缺口因为换表而好看。乙：冲击闭合，腰围和 hs-CRP 同向下降，VO2max 协议固定且超过学习效应，PpgAge 移动落在误差带内故不写逆龄。甲会被市场当成成功，乙才是这张表上的改善。成绩单若不能把甲乙分开，它就还在卖橡皮。

分数可以当过程指标；终点仍然是事件有没有被推迟、失能不能不能被压缩。过程指标要向终点鞠躬，而不是代替终点。鞠躬的具体动作就是这张表：几周问闭合，一季问同向，一年问储备，大事之年问回落，研究层问预演是否变得更准。哪一行没测，哪一行就空着。空着比填假数字更接近管理。

门诊里可以把这张表缩成五格手写。第一格：几周行，闭合 / 未闭合 / 未测。第二格：一季行，同向 / 冲突（先信实验室或反向未回落） / 未测。第三格：一年行，储备三项各写改善、恶化、练习效应无法判定、或空白。第四格：若今年有手术、感染、分娩，回落时钟是否关闭。第五格：研究层若做了芯片，只写预演是否更准，不写年龄。五格填完，这一次门诊的成功标准就已经可对质。缺格用空白，不用上一季的分数来填。林某第十二周只能填第一格的部分闭合、第二格的同向未满季、第三格空白、第四格无大事、第五格未复测。这样写很难看，但很难被改成“年轻了 0.6 岁”。难看，是这一章的功能。五格手写还有一个日历提醒：八到十二周不等于一季。十二周可以填几周行，一季行只能写“方向一致、尚未满季”，不能提前盖章。把十二周当成一季，会把还没走完的代谢同向写成已经成功，也会把一个化疗周期误当成大事之年已经结案。尺度错了，格子再工整也是假账。若同一年既做了 VO2max 年检，又经历一台手术，两行必须分开写：一年行看储备试验有没有按协议变慢，大事之年看术后窗口有没有闭合。用术后三个月还没回来的步数去填 VO2max 的失败，或用一次跑台成绩去宣布手术已经恢复，都是串行。日历上两件事情可以重叠，成绩单上两格不能合并。

> 穿戴变好而肝酶变坏，先信实验室。实验室平坦而冲击未回落，不得宣布成功。年尺度的 VO2max（或等价试验）、握力和认知成套若从未定义，一年行保持空白。误差带内的 PpgAge 移动不是逆龄。违反这四句中的任何一句，第十九章的七件事都会重新变成形容词。

冲突规则还有一个容易被忘掉的方向：化验变好而功能储备变差。转氨酶下来了，握力和步行速度掉了，一季行不能只摘肝酶。同向的成员里必须有一项功能，不能全是实验室里会动的酶。一年行的认知成套也要预先登记版本。换一套更简单的测验让分数上升，记为无法判定，不算改善。第二十章把练习效应写成空白的亲戚，就是为了挡住这种换尺。换尺发生时，一年行保持空白，并注明测验版本已变。版本未预先登记，同样记无法判定。无法判定比假改善更接近第二十章。
