# 第二十章 用曲线语言写清成功标准

不要用“年轻五岁”当 KPI。对个人，成功应当是可重复测量的轨迹改变。轨迹改变有时间尺度。尺度错了，会把噪声当成逆龄，或把尚未发生的回落当成失败。

| 时间尺度 | 看什么 | 谁测 |
|---|---|---|
| 周 | 冲击后是否回到本人包络（HRV、睡眠、静息心率、CGM） | 穿戴 |
| 季 | 代谢与炎症是否同向（腰围、血压、HbA1c、肝酶、hs-CRP） | 实验室 |
| 年 | 功能年龄缺口是否不再扩大；器官储备测试是否恶化减慢 | 穿戴钟 + 影像 / 功能试验 |
| 事件年 | 手术 / 感染 / 孕后，生理年龄是否在数月内回落 | 穿戴纵向 |
| 研究层 | 个人类器官在老年血清中的失能是否减轻 | 细胞平台 |

## 怎样才算改善

周尺度的成功是闭合：冲击发生了，包络收回来了。收不回来，就还在冲击里，不应开始庆祝任何分数。

季尺度的成功是同向：腰围、血压、糖化、肝酶、hs-CRP 不必每一项都完美，但方向应与穿戴斜率一致。穿戴变好而炎症和肝酶变坏，优先相信实验室，回头查传感器和依从性。

年尺度的成功是缺口不再扩大，储备测试的恶化减慢。这是压缩失能时间的代理，不是寿命上界的代理。

事件年的成功是回落。孕期生理年龄上升可以是预期；产后数月仍不回落，才是问题。手术和感染同理。

研究层的成功属于风洞自身：老年血清中的失能是否减轻。它可以支持下一轮预演，不可以直接写进客户的年龄。

## 临床翻译

曲线改善的临床翻译是：**压缩发病前的失能时间**，降低第一次心梗、第一次失代偿心衰、第一次显著认知下降的提前量。不是保证寿命上界。

把翻译写清楚，是为了让成功可被辩护。辩护的对象包括本人、医生、以及任何想把分数卖成延寿的人。分数可以当作过程指标；终点仍是事件是否被推迟、失能是否被压缩。过程指标向终点鞠躬，而不是代替终点。
