# 第二十章 怎样才算改善

请不要用“年轻五岁”当成绩单。对个人，成功应当是能反复测到的轨迹变化。变化有时间尺度。尺度错了，就会把噪声当成逆龄，或把还没走完的回落当成失败。

| 时间 | 看什么 | 谁来测 |
|---|---|---|
| 几周 | 冲击后有没有回到自己的范围（心率变异、睡眠、静息心率、连续血糖） | 穿戴 |
| 一季 | 代谢和炎症有没有同向（腰围、血压、糖化血红蛋白、肝酶、超敏 C 反应蛋白） | 实验室 |
| 一年 | 功能年龄缺口有没有继续扩大；器官储备测试恶化有没有变慢 | 穿戴钟 + 影像 / 功能试验 |
| 大事之年 | 手术、感染、怀孕过后，生理信号有没有在数月内回落 | 穿戴的纵向记录 |
| 研究层 | 个人类器官在老年血清里的失能有没有减轻 | 细胞平台 |

## 怎样读这些尺度

几周的成功是闭合：冲击发生了，范围收回来了。收不回来，就还在冲击里，不应开始庆祝任何分数。

一季的成功是同向：腰围、血压、糖化、肝酶、炎症不必每一项都完美，但方向应和手环上的速度一致。手环变好而炎症和肝酶变坏，优先相信实验室，回头查传感器和有没有坚持做。

一年的成功是缺口不再扩大，储备测试的恶化变慢。这是在压缩发病前那段失能时间，不是在抬高寿命天花板。

大事之年的成功是回落。孕期生理年龄上升可以是预期；产后数月仍不回来，才是问题。手术和感染同理。

研究层的成功属于风洞自己：老年血清里的失能有没有减轻。它可以支持下一轮预演，不可以直接写进客户的年龄。

## 翻译成健康语言

曲线改善，翻译过来就是：**把发病前那段失能的时间压短**，让第一次心梗、第一次心衰、第一次明显的认知下降来得晚一点。不是保证能活到某个岁数。

分数可以当过程指标；终点仍然是事件有没有被推迟、失能不能不能被压缩。过程指标要向终点鞠躬，而不是代替终点。
