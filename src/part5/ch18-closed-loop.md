# 第十八章 接成一个能检验的闭环

链条必须接成闭环，作用才检验得了。开环的穿戴只是仪表盘。开环的细胞平台只是展览。闭环才是管理。

```
连续穿戴 / 家用检测
    → 发现：速度变陡，或冲击没有回来
血液时钟（可选）+ 化验 / 影像
    → 确认：哪个系统已经在分子或结构上动了
个人干细胞做成的心 / 肝 / 神经 / 内皮，加上老年血清
    → 解释：是遗传薄点、药物不耐受，还是微环境衰老
    → 预演：下一干预在副本上是好是坏
医生选择一到两个动作
    → 八到十二周后再用手环和化验看速度有没有回来
```

## 闭环为什么必须短

动作必须少。一次选一到两个，不是选一套礼包。观察窗必须有界：八到十二周足够看见速度，不够假装延寿。回看必须用同一把尺子：手环上自己的范围、化验是否同向、必要时再测相关的细胞模块。哪一环缺了，链条就重新变成故事。

医生在闭环里不是签名栏。医生负责问：哪一步值得改这条曲线。值得，包括适应症、禁忌、和指南的关系、这个人眼下最该优先什么。风洞可以淘汰有害选项，不能代替这一步。手环可以显示回落，不能自己开药。

## 允许失败被看见

闭环在科学上的价值，是失败也能被看见。干预八周，速度没有回来，就应当停，而不是再加一项神秘手段把失败盖住。失败是信息：机制可能不匹配，依从性可能不够，冲击可能还在，薄点可能在还没测到的器官。下一次风洞或下一次门诊，应当被这次失败改写。一个不能失败的系统，一定在卖希望。
