# 关于本书

《可管理的衰老》是 [agemoco](https://github.com/javik-heart/agemoco) 仓库中的一本开放电子书。它用 mdBook 编写，随仓库在 GitHub Pages 上发布。

书的骨架是同目录下的论证提纲：从连续穿戴监测到 iPSC 细胞与类器官计算平台，如何把个人衰老从命运改写成可测量、可解释、可有限度改写的轨迹。提纲负责把命题收束到可辩护的长度；书负责把每一节写成能独立阅读的章节。

本书讨论科学模型、证据与边界，**不构成诊疗建议**。任何干预都应在执业医师的判断下进行。

源码与修订历史见 GitHub 仓库。欢迎就论证边界提出异议：可辩护，是这本书对自己提出的唯一标准。
