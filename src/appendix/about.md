# 关于本书

《可管理的衰老》是 [agemoco](https://github.com/javik-heart/agemoco) 仓库里的一本开放电子书，用 mdBook 编写，随仓库在 GitHub Pages 上发布。

书的骨架是同目录下的论证提纲：从连续穿戴监测到个人干细胞与类器官计算，怎样把衰老从命运改写成可以测量、可以解释、可以有限度改写的轨迹。提纲负责把话说短；书负责把每一节写成能独立阅读的科普章节。

本书讨论科学认识与证据边界，**不构成诊疗建议**。任何干预都应在执业医师的判断下进行。

源码和修订历史见 GitHub 仓库。欢迎就边界提出异议：能把话说准，是这本书对自己提出的唯一标准。
