# 关于本书

《可管理的衰老》是开放电子书，源码在 [agemoco](https://github.com/javik-heart/agemoco)，用 mdBook 编写。在线阅读见 GitHub Pages。论证提纲 `guide.md` 只给作者和审稿人核对，不是读者入口。

## 作者立场

作者张家林。本书把可辩护的命题收窄为：**衰老轨迹的速度、冲击和器官脆弱可以测量、解释、并有限度地改写；可管理不是已经逆龄。** 减少有害干预被明确写成健康贡献。作者不把培养皿有效写成人体延寿，也不把穿戴缺口写成个人诊断。

## 利益冲突

本书不推销特定手表、芯片、诊所或抗衰商品。若后续版本与商业实体发生资助、股权或顾问关系，应在本页更新。当前版本无此类关系需要申报。引用文献不等于背书其商业转化。

## 数据与模型

个人细胞数据、穿戴原始波形和可识别健康信息，**不得默认拿去训练对外模型**。这是第二十一章的第六条边界，也是命题能被公众辩护的条件。演示用的假想档案（林某）是虚构的，不是真实病历。

## 欢迎异议

能把话说准，是这本书对自己提出的唯一标准。挑战请开 GitHub issue，模板在 [`.github/ISSUE_TEMPLATE/challenge.md`](https://github.com/javik-heart/agemoco/blob/main/.github/ISSUE_TEMPLATE/challenge.md)：

1. 挑战哪一条命题（抄原句、注章节）；
2. 依据哪篇文献（作者、年份、DOI，以及是支持、削弱还是只相关）；
3. 你认为应改成哪一句（不接受把承诺扩大成逆龄）。

本书讨论科学认识与证据边界，**不构成诊疗建议**。任何干预都应在执业医师的判断下进行。
