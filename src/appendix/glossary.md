# 术语表

这里只收书中反复出现、又特别容易被说偏的词。更细的实验术语见各章正文。

**生物学年龄 / 生理年龄**  
用生理信号或分子标记估计的“相当于多大”。本书把它当过程指标，不当成身份，也不精确到小数点当作个人诊断。

**功能年龄缺口**  
估计年龄减去日历年龄。正缺口表示超前。关心的是它有没有扩大、冲击后有没有回落，而不是单次绝对值。

**PpgAge**  
用手腕脉搏波做的可穿戴衰老钟。在大规模队列里，和心脏代谢疾病、行为以及孕期等纵向跳变有关。

**DunedinPACE**  
分子速度计。数值大于 1 表示跑得比常模快。测的是速度，不是位置。

**底盘**  
由基因组、发育和早年环境决定的储备上限与背景脆弱。改得最慢，必须先被认识。

**速度**  
同一套基因组在当前负担下实际变老有多快。睡眠、代谢、炎症主要改这一层。

**冲击 / 台阶**  
一次事件把曲线抬高。关键是回落后能不能回到自己原来的范围，还是变成新地面。

**失代偿**  
还没到某病的诊断阈值，但已经不能在原来的高度上再扛下一次打击。

**本人常模**  
用三十到九十天建立的个人基线范围。穿戴管理以它为坐标，而不是以同龄平均为坐标。

**iPSC（诱导多能干细胞）**  
把体细胞重编程得到的多能细胞。完全重编程会大规模重置表观年龄。

**类器官 / 器官芯片**  
三维组织或芯片上的器官模块，可以加入老年血清、脂毒、药物，做个人器官风洞。

**衰老流形**  
许多个体轨迹共同栖居的更低维几何。大规模数据用来估计它，数学模型用来分析它。

**表观重置**  
重编程后甲基化年龄等指标大幅变年轻。这是方法本身的特征，不是客户已经逆龄。

**SASP**  
衰老相关分泌表型。衰老细胞向周围释放的促炎和重塑因子。

**风洞**  
本书对个人细胞平台的比喻：测脆弱、恢复力和益损，不测“现在几岁”。

**种子**  
保存相对年轻的自体细胞，供将来合规的细胞治疗。不是当前疗效。
