# 第一章 先把曲线说准确

“每个人都有一条天生的衰老曲线。”这句话听起来像科学，用错了就是命运论。

它的合理内核是：衰老不是随机噪声。基因组、发育史、早期环境，会给后来几十年的器官储备和修复能力设下强约束。同卵双生子的寿命相关、家族性长寿的聚集、某些单基因对血脂和癌症风险的巨大效应，都在提醒我们：基线不是一张白纸。

它的危险内核是：把约束说成死刑判决。一旦曲线被画死，后面只剩两种生意。一种卖认命，一种卖逆转。两者都不需要测量斜率，也不需要解释器官。

更精确的模型是**三条过程的叠加**，而不是一条寿命线：

1. **基线形状（set-point）**  
   你大概会在什么高度上老：储备上限、修复效率、代谢和电生理的背景。
2. **实现斜率（pace）**  
   同一基因组，在这一年实际跑得有多快。
3. **冲击与失代偿（shocks）**  
   一次事件把曲线抬高一截之后，是回落，还是变成新平台。

这三层对应三种完全不同的干预伦理。Set-point 大多不能被生活习惯改写，但必须被认识，否则资源会平均洒在所有器官上。Pace 是睡眠、运动、代谢负荷、炎症真正能改的部分。Shocks 是监测密度和临床窗口真正要抢的部分：孕期、感染、手术、化疗、急剧增重，都不是“又老了一岁”，而是轨迹上的台阶。

> [!TIP]
> 百岁老人及其子女的生物学，往往不是“从不衰老”，而是**同样年龄下斜率更平、冲击后恢复更快**。把长寿理解成抗性与恢复力，而不是不死，后面的 iPSC 库才有正确用法。

因此，本书后文所谓“改写衰老曲线”，从不等于改写出生日期，也不等于承诺上限寿命。它只要求三件事同时可被测量：斜率是否变陡，冲击是否回落，薄点是否被认出来。认不出来薄点，斜率管理就会退化成“多睡、多走”——对一部分人有效，对遗传性脂代谢、药源性心肌脆弱、蛋白病背景几乎无效。

下一章从 set-point 开始。它是整条链里最不像产品、却最决定资源该往哪堆的一层。
