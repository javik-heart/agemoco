# 第一章 先把曲线说准确

“每个人都有一条天生的衰老曲线。”这话听起来很科学。说对了，它提醒我们：衰老不是掷骰子。说错了，它就变成命运论——线已经画死，剩下的只是认命，或者买希望。

合理的那一半是真的。基因组、母亲肚子里的十个月、童年的营养和炎症，都会给后来几十年的器官储备设下约束。同卵双胞胎的寿命往往更接近，长寿会在家族里扎堆，某个基因就能大幅改变血脂或癌症风险。底盘不是一张白纸。

危险的那一半也很常见：把约束说成判决。曲线一旦被画死，世上就只剩两种生意。一种卖认命，一种卖逆转。两者都不需要量你走得多快，也不需要问你的心和肝谁更薄。

更准确的图像，是三条过程叠在一起，而不是一条寿命线。

**底盘**，决定你大概会在什么高度上老：储备有多少，修复有多勤快，代谢和心跳的背景噪声是什么样。

**速度**，决定同一套基因组在这一年实际跑得有多快。睡不好的一年、肚子迅速变厚的一年，都可以把一个日历年过成一年半。

**台阶**，是一次事件把路抬高之后，你是走回原来的高度，还是从此在新的地面上继续走。感染、怀孕、化疗、手术、长期失眠，都是台阶，不是“又老了一岁”。

这三层对应三种完全不同的做法。底盘大多改不了，但必须先认出来，否则资源会平均洒在所有器官上。速度才是睡眠、运动、体重真正能改的部分。台阶则要靠更密的监测去抢时间：不是等病名出现，而是问这次冲击有没有走完。

> [!TIP]
> 百岁老人往往不是“时间把他们忘了”。他们也在老，只是同样年纪下降得更慢，摔过一跤之后更容易站回来。把长寿理解成抗打和恢复，而不是不死，后面用他们的细胞做研究，才不会走偏。

因此，后文说“改写衰老曲线”，从来不是改出生日期，也不是保证你能活到某个岁数。它只要求三件事能被看见：速度有没有变陡，冲击有没有回落，薄点有没有被认出来。认不出薄点，管理就会退化成“多睡、多走”——对一部分人很有用，对天生脂代谢差、心肌特别怕某些药、或者蛋白清理能力弱的人，几乎使不上力。

下一章先看底盘。它最不像产品，却最决定力气该往哪使。
